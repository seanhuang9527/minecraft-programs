## 使用方式

1. 點進單一程式頁面，先查看準備方式與 Agent 起始位置。
2. 在 Minecraft Education 的 MakeCode 建立空白專案，再依程式逐塊完成。
3. 上課前先切換至積木模式檢查並實機測試。
4. 完成功能測試後，使用頁面中的活動建議實際玩一次。

> 第一批程式依既有教學資料整理，尚未在本次發布流程中重新實機驗證。
